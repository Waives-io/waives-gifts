# waives-gifts

המתנות של waives. כל מתנה בתיקייה משלה, והתוצרים של הלקוחות בתוך התיקייה של המתנה.

- `index.html` - הדף הראשי שמציג את כל המתנות
- `site/index.html` - מתנה: דף נחיתה לעסק (האשף)
- `site/<שם-העסק>/index.html` - האתרים שהלקוחות בחרו. Make מוסיף אותם אוטומטית
- `_redirects` - קישורים קצרים לקהילות, למשל `/freelancer`

מתנה חדשה: תיקייה חדשה עם `index.html`, כרטיס חדש בדף הראשי, ושורה ב-`_redirects` אם יש קישור לקהילה.
